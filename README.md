# ✨ Magical Night Photo Booth

เว็บแอป Photo Booth สำหรับงาน outing ธีม **Magical Night** (น้ำเงินเข้ม–ทอง)
ถ่าย 4 ช็อต → วางลงกรอบ → ได้ไฟล์ JPG (1200×1800) และ GIF เคลื่อนไหว (600×900) ดาวน์โหลดลงเครื่องได้ทันที
ทำงานบนเบราว์เซอร์ทั้งหมด ไม่มี backend

- Vite + React + TypeScript
- สร้าง GIF บนเครื่องด้วย [gifenc](https://github.com/mattdesl/gifenc)
- รองรับ Google Chrome, Microsoft Edge, Safari (macOS และ iPad)

---

## 1. วิธีรัน

ต้องมี Node.js **20.19 ขึ้นไป** (แนะนำ 22 LTS)

```bash
npm install
npm run dev        # เปิดโหมดพัฒนา
```

เปิดเบราว์เซอร์ที่ `https://localhost:5173`

> เซิร์ฟเวอร์ใช้ HTTPS แบบ self-signed (จาก `@vitejs/plugin-basic-ssl`) ครั้งแรกเบราว์เซอร์จะเตือนว่า "การเชื่อมต่อไม่เป็นส่วนตัว"
> - Chrome / Edge: กด **ขั้นสูง** › **ไปยัง localhost (ไม่ปลอดภัย)**
> - Safari: กด **แสดงรายละเอียด** › **เยี่ยมชมเว็บไซต์นี้**

คำสั่งอื่น ๆ

| คำสั่ง | ใช้ทำอะไร |
| --- | --- |
| `npm run build` | ตรวจ TypeScript และ build ไฟล์ไปที่ `dist/` |
| `npm run preview` | เปิดไฟล์ที่ build แล้วที่ `https://<ip>:4173` (แนะนำให้ใช้ในวันงาน) |
| `npm run typecheck` | ตรวจ TypeScript อย่างเดียว |

### ใช้งานบนคอมพิวเตอร์ในวันงาน
1. `npm run build && npm run preview`
2. เปิด `https://localhost:4173` ด้วย Chrome หรือ Edge
3. กดปุ่ม **เต็มจอ** มุมขวาบน
4. กด **Spacebar** หรือคลิกปุ่มเพื่อเริ่มถ่าย และเริ่มนับถอยหลัง

## 2. วิธีเปิดบน iPad

iPad (Safari) อนุญาตให้ใช้กล้องเฉพาะเว็บที่เป็น **HTTPS** เท่านั้น โปรเจกต์นี้ตั้งค่า `server.host = true` ไว้แล้ว เลยเปิดผ่าน Wi-Fi วงเดียวกันได้

1. ให้คอมพิวเตอร์และ iPad ต่อ **Wi-Fi วงเดียวกัน**
2. บนคอมพิวเตอร์รัน `npm run dev` (หรือ `npm run build && npm run preview`)
3. ดูบรรทัด `Network:` ใน terminal เช่น `https://192.168.1.23:5173/`
4. บน iPad เปิด **Safari** แล้วพิมพ์ที่อยู่นั้น
5. Safari จะเตือนเรื่องใบรับรอง → แตะ **แสดงรายละเอียด** › **เยี่ยมชมเว็บไซต์นี้** › ยืนยัน
6. เมื่อ Safari ถามสิทธิ์กล้อง ให้แตะ **อนุญาต**

> ถ้าเปิดไม่ได้ ให้ตรวจ firewall ของคอมพิวเตอร์ (macOS: การตั้งค่าระบบ › เครือข่าย › ไฟร์วอลล์ / Windows: อนุญาต Node.js ใน Private network)
> Wi-Fi บางที่ (เช่น Wi-Fi โรงแรม/Guest) ห้ามอุปกรณ์คุยกันเอง ให้ใช้ hotspot จากมือถือแทน

### เพิ่มลงหน้าโฮม (เต็มจอแบบแอป)
1. เปิดเว็บใน Safari ตามขั้นตอนด้านบน
2. แตะปุ่ม **แชร์** (สี่เหลี่ยมมีลูกศรขึ้น) › **เพิ่มไปยังหน้าจอโฮม** › **เพิ่ม**
3. เปิดจากไอคอน **Magical Booth** บนหน้าโฮม แอปจะเปิดเต็มจอ ไม่มีแถบที่อยู่
4. ถ้ากล้องไม่ขึ้นในโหมดนี้ ให้ไปที่ **การตั้งค่า › Safari › กล้อง** เลือก **อนุญาต** แล้วปิด–เปิดแอปใหม่

> หมายเหตุ: ไอคอนบนหน้าโฮมจำ IP ของคอมพิวเตอร์ไว้ ถ้า IP เปลี่ยน ต้องลบไอคอนแล้วเพิ่มใหม่

## 3. วิธีเพิ่มกรอบใหม่

### 3.1 เทมเพลตสำหรับพิมพ์ (1024×1536) — `public/frames/templates.json`

เทมเพลตสำหรับพิมพ์ขึ้นเป็นตัวเลือกแรก ๆ ในหน้าเลือกกรอบ ได้แก่ `castle-classic`, `enchanted-garden` และ `moonlit-castle` แอปอ่านรายการเทมเพลตจาก `templates.json` ตอนเปิดแอป

- `canvas`: ขนาดเทมเพลต ซึ่งเป็นขนาดของไฟล์ JPG ที่ได้ด้วย (1024×1536)
- `photoSlots`: 4 ช่องเรียงตามลำดับ **บนซ้าย, บนขวา, ล่างซ้าย, ล่างขวา** ช็อต 1–4 จะลงช่องตามลำดับนี้
- `templates`: รายการไฟล์ PNG ใน `public/frames/`

**วิธีวาด:** วาดรูปเทมเพลตก่อน แล้ววางรูปถ่ายแต่ละช็อตแบบครอปกึ่งกลางให้เต็มช่องสี่เหลี่ยม (cover, มุมฉาก) รูปจะอยู่ในช่องเท่านั้น เส้นกรอบและลายมุมจึงไม่ถูกรูปทับ

- เพิ่มเทมเพลตใหม่: วาง PNG ใน `public/frames/` แล้วเพิ่ม `{ "id": "...", "file": "....png", "name": "ชื่อที่แสดง" }` ใน `templates`
- ถ้าเส้นกรอบของเทมเพลตไหนเยื้องจากค่ากลาง ให้ใส่ `"photoSlots": [...]` เฉพาะในรายการของเทมเพลตนั้น ค่านี้จะใช้แทนค่ากลาง ไม่ต้องแก้รูป
- GIF ของเทมเพลต: เติมรูปลงช่องทีละช็อต (1 → 1–2 → 1–3 → ครบ 4) เพื่อไม่ให้รูปทับเส้นกรอบ

**พิมพ์ 4×6 นิ้ว:** หน้าดาวน์โหลดมีปุ่ม "พิมพ์รูป 4×6 นิ้ว" (ไม่พิมพ์เองอัตโนมัติ) ในหน้าต่างพิมพ์ให้เลือกกระดาษ **4×6 in / 10×15 cm แนวตั้ง** ปิด "Headers and footers" และตั้งมาตราส่วนเป็น 100% / "Actual size" ถ้าเครื่องพิมพ์รองรับแบบไร้ขอบให้เลือก **Borderless**

### 3.2 กรอบแบบเดิม (1200×1800) — `src/config/frames.ts`

1. ออกแบบรูปกรอบขนาด **1200×1800 px** บันทึกเป็น PNG
   - **backgroundImage**: ภาพพื้นหลังทั้งแผ่น (รูปถ่ายจะถูกวางทับบนตำแหน่ง slot)
   - **overlayImage** (ไม่บังคับ): PNG พื้นโปร่งใส วางทับบนสุด ใช้กับของตกแต่งที่อยากให้ทับรูป เช่น ประกายดาว มุมกรอบ
2. วางไฟล์ไว้ที่ `public/frames/` เช่น `public/frames/frame-4.png`
3. เพิ่มข้อมูลใน `src/config/frames.ts`

```ts
{
  id: 'my-new-frame',              // ไม่ซ้ำกัน
  name: 'ชื่อกรอบที่แสดงบนจอ',
  backgroundImage: '/frames/frame-4.png',
  overlayImage: '/frames/frame-4-overlay.png', // ไม่ใส่ก็ได้
  slots: DEFAULT_SLOTS,            // หรือกำหนดเองด้านล่าง
},
```

ตำแหน่ง slot ค่าเริ่มต้น (หน่วย px บนภาพ 1200×1800)

| ช่อง | x | y | width | height |
| --- | --- | --- | --- | --- |
| 1 | 50 | 60 | 530 | 640 |
| 2 | 620 | 60 | 530 | 640 |
| 3 | 50 | 740 | 530 | 640 |
| 4 | 620 | 740 | 530 | 640 |

ถ้าต้องการตำแหน่งอื่น ให้กำหนด `slots: [{ x, y, width, height }, ...]` 4 ช่องตามลำดับช็อต

**ลำดับการวาด:** พื้นหลัง (ยืดเต็ม 1200×1800) → รูป 4 ช็อต (ครอปกึ่งกลางแบบ cover มุมโค้ง 12px) → overlay

**GIF:** แต่ละเฟรมของ GIF แสดง 1 ช็อตเต็มพื้นที่รวมของทุก slot (ค่าเริ่มต้นคือกรอบสี่เหลี่ยมที่ครอบ slot ทั้ง 4) แล้ววาดพื้นหลังและ overlay ของกรอบเดียวกัน
- ถ้า overlay มีลายตรงกลางระหว่างช่อง ลายนั้นจะทับรูปใน GIF ด้วย แนะนำให้ใส่ของตกแต่งไว้ที่ขอบนอก
- เปลี่ยนพื้นที่ของ GIF ได้ด้วย `gifSlot: { x, y, width, height }`

**ถ้าโหลดรูปกรอบไม่ได้** (ชื่อไฟล์ผิด/ไม่มีไฟล์) แอปจะใช้กรอบสำรองที่วาดด้วยโค้ด (gradient น้ำเงินเข้ม + เส้นขอบทอง) ให้อัตโนมัติ

## 4. ตั้งค่า Guided Access บน iPad (ล็อกให้อยู่ในแอปเดียว)

Guided Access ป้องกันไม่ให้แขกกดออกจากแอป ปัดไปหน้าโฮม หรือเปิดแอปอื่น

**เปิดใช้ครั้งแรก**
1. **การตั้งค่า › การช่วยการเข้าถึง › การเข้าถึงที่ได้รับการชี้แนะ** (Guided Access) › เปิด
2. แตะ **การตั้งค่ารหัส** › **ตั้งรหัสการเข้าถึงที่ได้รับการชี้แนะ** แล้วตั้งรหัส 6 หลัก (หรือเปิด Face ID / Touch ID)
3. แนะนำให้ตั้ง **การตั้งค่า › จอภาพและความสว่าง › ล็อกอัตโนมัติ › ไม่ใช้เลย** และเสียบสายชาร์จไว้ตลอดงาน

**เริ่มล็อก**
1. เปิดแอป Magical Booth (จากไอคอนหน้าโฮม) หรือ Safari หน้าแอป
2. กดปุ่มด้านบน (ปุ่ม Power) **3 ครั้งติดกัน** (iPad ที่มีปุ่มโฮม ให้กดปุ่มโฮม 3 ครั้ง)
3. แตะ **ตัวเลือก** › ปิด **ปุ่มปรับเสียง** และ **การเคลื่อนไหว** (ถ้าไม่อยากให้หมุนจอ) › แตะ **เริ่ม**

**ออกจากการล็อก**: กดปุ่มด้านบน 3 ครั้ง › ใส่รหัส › **สิ้นสุด**

> ถ้าใช้ Guided Access กับ Safari (ไม่ใช่ไอคอนหน้าโฮม) แขกจะยังกดแถบที่อยู่ได้ ให้วาดวงกลมคลุมแถบที่อยู่ในหน้าจอ Guided Access เพื่อปิดการแตะบริเวณนั้น

## 5. การตั้งค่าในโค้ด

ไฟล์ `src/config/app.ts`

| ค่า | ค่าเริ่มต้น | ความหมาย |
| --- | --- | --- |
| `MIRROR_OUTPUT` | `false` | `false` = รูปผลลัพธ์ถูกด้านเหมือนจริง (ตัวหนังสืออ่านได้) แม้พรีวิวบนจอจะกลับด้านเหมือนกระจก · `true` = รูปผลลัพธ์กลับด้านเหมือนพรีวิว |
| `COUNTDOWN_FIRST_SECONDS` | `5` | นับถอยหลังก่อนช็อตแรก |
| `COUNTDOWN_NEXT_SECONDS` | `3` | นับถอยหลังก่อนช็อต 2, 3 และ 4 |
| `IDLE_TIMEOUT_MS` | `60000` | ไม่มีการใช้งานนานเท่านี้ กลับหน้าแรกอัตโนมัติ |
| `JPG_QUALITY` | `0.92` | คุณภาพไฟล์ JPG |
| `GIF_FRAME_DELAY_MS` | `600` | เวลาต่อเฟรมของ GIF |

รูปดิบของแต่ละช็อต (ไม่มีกรอบ ไม่กลับด้าน ความละเอียดเต็มของกล้อง) เก็บแยกไว้ใน state `shots` (`src/types.ts` › `Shot`) เพื่อใช้ทำฟีเจอร์เปลี่ยนพื้นหลังในอนาคต
