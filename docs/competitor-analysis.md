# เทียบกับ "My Name is PhotoBooth" (mynameisphotobooth.online)

สำรวจเมื่อ 12 พ.ย. 2026 จากหน้าแรก หน้าราคา ศูนย์ช่วยเหลือ และคำถามที่พบบ่อย ไม่ได้สมัครบัญชี จึงยังไม่เห็นหน้า Kiosk / Live Wall จริง

## ภาพรวมของเขา
เป็น SaaS ที่ต้องสมัครบัญชีและสร้างอีเวนต์ในหลังบ้าน รูปเก็บบน server ของผู้ให้บริการ

| แพ็กเกจ | ราคา | จุดสำคัญ |
| --- | --- | --- |
| Free | ฟรี | ฟีเจอร์หลักครบ แต่มีลายน้ำ เก็บรูป 7 วัน |
| Event Pass | ฿590 / 7 วัน | ไม่มีลายน้ำ ต่อกล้องภายนอกได้ |
| Pro | ฿1,490 / 30 วัน | ไม่มีลายน้ำ เก็บรูป 30 วัน |
| การศึกษา | ฟรี | สิทธิ์ระดับ Pro สำหรับอีเมล .ac.th |

ฟีเจอร์ที่ประกาศไว้: กรอบ 40 แบบ + อัปโหลดกรอบแล้วหาช่องรูปอัตโนมัติ · วิดีโอ 3 วินาทีในกรอบ · QR รับไฟล์พร้อมแคปชันและแฮชแท็ก · Live Photo Wall พร้อมซ่อนรูป · พิมพ์อัตโนมัติผ่านโปรแกรม Print Bridge (ต้องลง Node.js) · ฟอร์มเก็บรายชื่อพร้อม PDPA · เก็บรูปในเครื่องตอนเน็ตหลุด · โหมดเซลฟี่ด้วยมือถือแขก · สติกเกอร์ · คลังสำรองพร้อม zip · หลังบ้าน สถิติ และสิทธิ์ทีม · รายงานสรุปหลังจบงาน · พิมพ์แถบ 2×6 สองใบบนกระดาษ 4×6

## ส่วนที่เราดีกว่า
1. ฉากเวทมนตร์ด้วย AI ตัดคน (เขาไม่มี)
2. ฟิลเตอร์สี 6 แบบ (เขาไม่มี)
3. ไม่มีลายน้ำ ไม่มีค่าใช้จ่าย และต่อกล้อง Sony ได้ฟรี
4. รูปไม่ออกจากเครื่อง และใช้งานได้แม้ไม่มีเน็ต ดีกว่าเรื่อง PDPA
5. ไม่ต้องสมัครบัญชี เปิดเว็บแล้วใช้ได้เลย
6. ประสบการณ์ตามธีมครบ ทั้งเสียง ประกาย และการนับถอยหลัง

## สิ่งที่ควรนำมาใช้ (เรียงตามความคุ้ม)

**ทำได้เลย ไม่ต้องมี server**
1. ปุ่มตั้งค่าบูธ: เลือกกล้องและความละเอียด แล้วจำค่าไว้ในเครื่อง (สำหรับกล้อง Sony)
2. กรอบอัตโนมัติจากชื่องานและสีแบรนด์ + อัปโหลดกรอบแล้วหาช่องรูปอัตโนมัติ
3. พิมพ์แถบ 2×6 นิ้ว 2 ใบบนกระดาษ 4×6 พร้อมเส้นตัด
4. รายงานสรุปหลังจบงาน + แกลเลอรีรูปทั้งงาน + ดาวน์โหลดเป็น zip

**เฟส B**
5. วิดีโอในกรอบ: อัดคลิปสั้นทุกช็อต แล้วรวมเป็นวิดีโอ 3 วินาที
6. สติกเกอร์ลากวาง

**เฟส C (ต้องมี server บน Google Cloud / Firebase)**
7. QR รับรูปพร้อมแคปชันและแฮชแท็ก + QR แกลเลอรีทั้งงาน
8. คิวอัปโหลดเมื่อเน็ตหลุด
9. Live Wall พร้อมซ่อนรูป + ใช้หลายเครื่องในงานเดียว
10. นโยบายเก็บรูป เช่น ลิงก์ใช้ได้ 7 วันแล้วลบอัตโนมัติ

**การพิมพ์อัตโนมัติ:** เริ่มจากเปิด Chrome ด้วย `--kiosk-printing` ซึ่งไม่ต้องลงโปรแกรมเพิ่ม ถ้าไม่พอค่อยทำโปรแกรมตัวกลางแบบ Print Bridge ของเขา

**ไม่ต้องทำ:** ระบบชำระเงิน ลายน้ำ ระบบชวนเพื่อน สิทธิ์ทีม และฟอร์มเก็บข้อมูลแขก (สำหรับงานภายในบริษัทไม่จำเป็น และเพิ่มภาระเรื่อง PDPA)
