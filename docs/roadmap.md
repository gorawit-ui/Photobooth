# แผนงาน (Roadmap)

## ✅ เสร็จแล้ว
- Flow ถ่ายรูป 4 ช็อต: ช็อตแรกนับถอยหลัง 5 วินาที ช็อตถัดไป 3 วินาที มีแฟลช thumbnail และกลับหน้าแรกเองเมื่อไม่มีคนใช้ 60 วินาที
- เทมเพลตพิมพ์ 1024×1536 จำนวน 3 แบบ อ่านช่องรูปจาก `templates.json` และพิมพ์ 4×6 นิ้วแนวตั้ง
- JPG รูปรวมในกรอบ + GIF ของรูป 4 ช็อต (ไม่มีกรอบ) ดาวน์โหลดได้ และแชร์บน iPad ได้
- ฉากเวทมนตร์ด้วย AI ตัดคน (MediaPipe ทำงานในเครื่อง ไม่ต้องใช้เน็ต) + ฟิลเตอร์สี 6 แบบ + เสียง + ประกายบนพรีวิว
- พร้อม deploy ขึ้น Vercel (`vercel.json`) และสรุป Tech Stack (`docs/magical-booth-tech-stack.pdf`)

## 🎨 กำลังทำ: ธีม "The Order of Unity"
- ม็อกดีไซน์อยู่ใน [`docs/design/`](./design/README.md)
- รอไฟล์กรอบและฉากจาก ChatGPT ทาง Google Drive แล้วนำเข้าแอป: วัดช่องรูป ใส่ตัวหนังสือไทย และเปลี่ยนสีและฟอนต์ของหน้าจอ

## ถัดไป (ไม่ต้องมี server)
1. ปุ่มตั้งค่าบูธ: เลือกกล้องและความละเอียด แล้วจำค่าไว้ (สำหรับ Sony a7C ผ่าน HDMI capture card)
2. กรอบจากชื่องานและวันที่ + อัปโหลดกรอบแล้วหาช่องรูปอัตโนมัติ
3. พิมพ์แถบ 2×6 สองใบบนกระดาษ 4×6
4. รายงานสรุปหลังจบงาน + แกลเลอรีในเครื่อง + zip
5. โจทย์ท่าโพสแต่ละช็อต

## เฟส B
- วิดีโอ 3 วินาทีในกรอบ (MediaRecorder) + boomerang
- สติกเกอร์ลากวาง

## เฟส C (ต้องมี server)
- ย้ายขึ้น Google Cloud ของบริษัท (แนะนำ Firebase Hosting) ด้วยโดเมนบริษัท เช่น `booth.tdfb.co`
- QR รับรูป GIF และคลิป พร้อมแคปชันและแฮชแท็ก + คิวอัปโหลดเมื่อเน็ตหลุด
- Live Wall + หน้าตั้งค่าลับ / โปรไฟล์ event

## สิ่งที่ต้องทดสอบด้วยเครื่องจริง
- Safari บน Mac และ iPad: กล้อง เสียง ความเร็วการตัดคน ดาวน์โหลด และการพิมพ์
- กล้อง Sony a7C ผ่าน HDMI capture card
- แสงและผนังจริงในห้องประชุม (คุณภาพการตัดคน)
